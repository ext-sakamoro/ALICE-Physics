# Engine identifiers that occur in string literals of the engine source and that the neutral browser
# package overwrites in its wasm data (scripts/neutral_pkg.py --data-literals).
#
#   <identifier> <file> <role>
#
# The build stops when it would overwrite an identifier that occurs in a literal of a file not
# listed here for it, when a listed line matches no such literal, or when the literal's line, or a
# line of the same file that uses the name the literal is bound to, names a hash (hash, law id,
# digest, sha, checksum, fingerprint, blake, fnv, crc32, .update). Identifiers in no literal
# (derived Debug text, panic locations) are not listed. Overwriting keeps the length, so only the
# text changes; scripts/test_neutral_pkg.py checks this list against the source in CI.
